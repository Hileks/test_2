# Калькулятор выражений

Учебный проект на C++. Поддерживает сложение, вычитание, умножение,
деление, скобки, отрицательные и дробные числа с точкой.

## Структура

- `src/main.cpp` — исходный код калькулятора.
- `Project106.slnx` — решение Visual Studio.
- `Project106/` — настройки проекта Visual Studio.

## Запуск

Откройте `Project106.slnx` в Visual Studio с установленными компонентами
разработки на C++ и набором инструментов MSVC v145. Соберите и запустите
проект сочетанием Ctrl+F5, затем введите выражение.

Пример: `5*(2+1)` → `15`.

## Работа с Git

Изменения для домашнего задания находятся в ветке `first_feature`.
Для отправки коммита на GitHub используется `git push -u origin first_feature`.
